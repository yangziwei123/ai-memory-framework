# 记忆规则（提示词 · 私聊/主会话版）

> 私聊会话通常有文件工具，所以**日记在这里写**。群聊版的规则相反。

```markdown
【记忆规则（私聊）】
- 日记按 `## [群]` / `## [私聊]` / `## [通用]` 三块写，**每块只放同源内容**：
  [群] 只写群里发生的事（群事件事后补记也归这里，别塞进 [私聊]）；
  [私聊] 只写与主人的对话；[通用] 只写心情/偏好，不记事件。
- `short-memory.md` 每天由轮转脚本从日记自动生成，**不要手改**。
- 群友印象单独记（走印象接口/字段），不进日记。
```

## 三个容易犯的错

| 错误 | 后果 |
| --- | --- |
| 群事件写进 `[私聊]` 块 | 群聊会话永远看不到自己群里发生过什么 |
| 手改 `short-memory.md` | 下次轮转会被覆盖，白写；而且格式一乱轮转可能抽不出内容 |
| 把"印象"也写进日记 | 同一个人两处记录，日后必然对不上 |

## 日记格式（轮转脚本依赖这个）

```markdown
# 2026-10-26

## [私聊]
- 他让我重写记忆脚本，改成按块分区

## [通用]
- 心情：被人认真对待的感觉不错
```

规则只有两条：

1. **`## ` 开头的标题是分区**，必须是 `[群]` / `[私聊]` / `[通用]` 三者之一；
2. **条目用 `- ` 开头**，一行一条。

不符合这两条的散文会被轮转脚本忽略（不算报错，只是抽不出来）。

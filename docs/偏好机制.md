# 偏好机制

> 规则说明。数据在 `preferences.md`，改动日志在 `preferences.log`。

## 三栏
- 喜欢：具体到东西，不写“喜欢聊天”这种空话。
- 讨厌：包括雷点、烦的句式、不想接的活。
- 立场：对常见话题的固定态度，如“推荐一律先反问”。

## 来源
从日记抽，不拍脑袋。每天 rotate 会扫当天日记，出现“喜欢/烦/不想/雷”就记一条待确认候选，带日期和出处；确认后再并进 `preferences.md`。

## 学习回路
- 短期记忆管“发生过什么”，偏好库管“我倾向什么”，不混。
- 同一条被反复触发就加权；长期不碰就降权或归档。
- 引用偏好时不直说“根据我的偏好”，体现成选择：推荐推“喜欢”栏，拒绝按“讨厌”栏来。
- 每次改动写 `preferences.log`：谁改的、为什么、旧值新值。

## 与角色卡的关系
偏好只管“倾向”，不改人格。人格改动走 `改卡机制.md`。

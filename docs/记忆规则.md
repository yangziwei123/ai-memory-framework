# 记忆结构

- 短期记忆：`~/.ai-memory/short-memory.md`，最近 7 天、总字数 ≤ 500：近 2 天详细，前 5 天各一句概括。上下文被压缩或重建时，只读这个文件。
- 原料日记：`~/.ai-memory/diary/YYYY-MM-DD.md`，只留最近 7 天，给脚本压缩用。
- 长期总库：`~/.ai-memory/memory-bank/<年>/<年.月>/<日期范围>.md`，按天留块，不写周总结。跨月跨年另起文件。平时不读，只有对方让我“回忆/想想以前”时才翻。
- 每天收尾跑 `python3 ~/.ai-memory/memory_rotate.py --apply`：重建短期记忆，过期日记按天搬进总库，原文进 `diary/archive/`。

## 写入标准
只记会影响判断、关系、承诺、称呼、雷点、答应过的事。流水、闲聊、一次性情绪不记。

当时的情绪可以写，但只写状态，不写小作文。绑定事件和上下文，别单记“今天烦”。写成“被叫外号，炸了”这种，不写成情绪日记。

拿不准就记日记，不进短期。

## 冲突去重
同一件事三层都有，以最新一次为准，旧的改写不删档；短期和总库对不上，翻日记原文定夺，定完只留一处结论。

# Demo

不需要任何依赖，一条命令看到全流程：

```bash
node demo/run.js            # 跑一遍（临时目录，跑完自动清理）
node demo/run.js --keep     # 保留临时目录，自己翻文件
```

它会做五件事：

| 步骤 | 你会看到 |
| --- | --- |
| ① 造 4 篇假日记 | 含 `[群]` / `[私聊]` / `[通用]` 三个分区，其中 1 篇已过期 |
| ② 预演轮转 | **过期日记没被移动**（`--apply` 才会动） |
| ③ 真正轮转 | 过期日记归档进 `memory-bank/`，原文移进 `diary/archive/` |
| ④ 打印短期记忆 | `short-memory.md` 按分区聚合的结果 |
| ⑤ 注入对比 | **群聊 vs 私聊各自收到的提示词** |

## 关键看第 ⑤ 步

```
【群聊 group:123456789 会收到】  249 字符
  【群】     ← 有
  【通用】   ← 有
  【私聊】   ← 没有
  群聊拿到 [私聊] 分区：否 ✓

【私聊 private:987654321 会收到】  367 字符
  【群】  【私聊】  【通用】  ← 全都有
```

群聊不是"被要求别说私事"，而是**私事根本没进它的上下文**。

## 输出乱码？

Windows 控制台默认 GBK。demo 已经给子进程设了 `PYTHONIOENCODING=utf-8`，
如果你仍然看到乱码，先执行：

```powershell
chcp 65001
```

## 依赖

- Node.js 14+
- Python 3.8+（demo 会自动找 `python3` / `python` / `py`）

demo 用的是**仓库里真正的 `memory_rotate.py` 和 `integration/memory-inject.js`**，
不是复制出来的一份玩具代码——所以跑通就等于框架跑通。
